This directory contains temporary vendor patches applied via cweagans/composer-patches to allow PHP 8 CI to run for diagnostics.

Current patch:
- `laravel-framework-collection-offsetExists-php8.patch` — adds `#[\ReturnTypeWillChange]` attributes to `ArrayAccess` methods on `Illuminate\Support\Collection` (offsetExists/get/set/unset) so older Laravel code does not fatal under PHP 8+.

Notes:
- These patches are temporary stop-gaps. They should be removed after upgrading Laravel and/or vendors to PHP 8 compatible releases.
- The patch is applied during `composer install` by `cweagans/composer-patches` (added to `composer.json`).

Usage:
- `composer install` will apply the patch automatically. If you want to remove the patch locally, revert the `extra.patches` section in `composer.json` and restore vendor files from `composer install --prefer-dist`.

Author: automated patch generated by CI-agent for diagnostics.
